## 01 · Python Basics

📖 Notes: [01_basics/README.md](01_basics/README.md)

<details>
<summary><b>1. Is Python compiled or interpreted?</b></summary>

Both. Python first compiles the source code to *bytecode* (`.pyc` files), and then the Python Virtual Machine interprets that bytecode.

</details>

<details>
<summary><b>2. What does &quot;dynamically typed&quot; mean? Is Python also strongly typed?</b></summary>

Dynamically typed means types are checked at runtime, and a variable can point to any type. Python is also strongly typed: it won't convert types implicitly, so `"1" + 1` is an error.

</details>

<details>
<summary><b>3. What is the difference between <code>==</code> and <code>is</code>?</b></summary>

`==` compares values. `is` compares identity, meaning whether both names point to the same object (`id()`).

</details>

<details>
<summary><b>4. What are mutable and immutable types? Give examples.</b></summary>

Mutable types can change in place: list, dict, set. Immutable types cannot: int, float, str, tuple, bool.

</details>

<details>
<summary><b>5. What is the difference between <code>/</code> and <code>//</code>?</b></summary>

`/` always returns a float (`7/2 = 3.5`). `//` does floor division (`7//2 = 3`, and `-7//2 = -4`).

</details>

<details>
<summary><b>6. What is <code>None</code>?</b></summary>

A special singleton object that means "no value". A function without a `return` returns `None`.

</details>

<details>
<summary><b>7. What are truthy and falsy values?</b></summary>

Falsy values are `0`, `0.0`, `""`, `[]`, `{}`, `set()` and `None`. All other values are truthy.

</details>

<details>
<summary><b>8. What does <code>x = &quot;&quot; or &quot;guest&quot;</code> give?</b></summary>

`"guest"`. `or` returns the first truthy operand, or the last operand if none are truthy. It doesn't always return a bool.

</details>

## 02 · Strings

📖 Notes: [02_strings/README.md](02_strings/README.md)

<details>
<summary><b>1. Why are strings immutable in Python?</b></summary>

Immutability makes strings **hashable**, so they can be dict keys and set members. It also makes them safe to share between variables, and lets Python reuse (intern) them to save memory.

</details>

<details>
<summary><b>2. How do you reverse a string?</b></summary>

`s[::-1]`. Another way is `"".join(reversed(s))`.

</details>

<details>
<summary><b>3. How do you check whether a string is a palindrome?</b></summary>

```python
clean = s.lower().replace(" ", "")
clean == clean[::-1]
```

</details>

<details>
<summary><b>4. What is the difference between <code>split()</code> and <code>split(&quot; &quot;)</code>?</b></summary>

With no argument, `split()` splits on **any whitespace** (spaces, tabs, newlines) and ignores repeated spaces. `split(" ")` splits on **each single space**, so `"a  b".split(" ")` gives `['a', '', 'b']`.

</details>

<details>
<summary><b>5. Why is <code>&quot;&quot;.join(list)</code> preferred over <code>+=</code> in a loop?</b></summary>

Each `+=` creates a new string and copies everything so far, which is O(n²) overall. `join` calculates the total size once and builds the result in one pass, which is O(n).

</details>

<details>
<summary><b>6. What is the difference between <code>find()</code> and <code>index()</code>?</b></summary>

Both return the position of a substring. If it isn't found, `find()` returns `-1` and `index()` raises a `ValueError`.

</details>

<details>
<summary><b>7. How do you count the frequency of each character in a string?</b></summary>

```python
from collections import Counter
Counter("banana")   # Counter({'a': 3, 'n': 2, 'b': 1})
```

</details>

<details>
<summary><b>8. What is a raw string?</b></summary>

A string prefixed with `r` where backslashes are not treated as escape characters. It's useful for Windows paths and regular expressions: `r"C:\new"`.

</details>

## 03 · Collections (list, tuple, set, dict)

📖 Notes: [03_collections/README.md](03_collections/README.md)

<details>
<summary><b>1. What is the difference between a list and a tuple?</b></summary>

A list is mutable and uses `[]`. A tuple is immutable and uses `()`. Tuples are slightly faster and use less memory, and they are hashable, so they can be dict keys. Use a tuple for data that shouldn't change.

</details>

<details>
<summary><b>2. Why can&#x27;t a list be a dictionary key?</b></summary>

Dict keys must be **hashable**: their hash must never change. A list can change, so its hash could change and the dict would lose track of the key. Tuples (of immutable items) are hashable.

</details>

<details>
<summary><b>3. How do you remove duplicates from a list?</b></summary>

`list(set(items))` loses the order. `list(dict.fromkeys(items))` keeps the original order.

</details>

<details>
<summary><b>4. What is the difference between <code>sort()</code> and <code>sorted()</code>?</b></summary>

`list.sort()` sorts **in place** and returns `None`. It only works on lists. `sorted(iterable)` returns a **new** list and works on any iterable.

</details>

<details>
<summary><b>5. What is the difference between <code>remove()</code>, <code>pop()</code> and <code>del</code>?</b></summary>

`remove(value)` deletes the first matching value. `pop(i)` deletes by index and **returns** the item (the last one by default). `del lst[i]` deletes by index or slice and returns nothing.

</details>

<details>
<summary><b>6. What is the difference between a shallow copy and a deep copy?</b></summary>

A shallow copy creates a new outer container, but the inner objects are still shared. A deep copy (`copy.deepcopy`) recursively copies everything, so nested changes don't affect the original.

</details>

<details>
<summary><b>7. What is the time complexity of <code>x in list</code> vs <code>x in set</code>?</b></summary>

For a list it is O(n), because Python checks every item. For a set or dict it is O(1) on average, because Python uses a hash lookup. Use a set when you check membership many times.

</details>

<details>
<summary><b>8. Are dictionaries ordered?</b></summary>

Yes, since Python 3.7 they keep insertion order. That is guaranteed by the language.

</details>

<details>
<summary><b>9. What is the difference between <code>dict[&quot;key&quot;]</code> and <code>dict.get(&quot;key&quot;)</code>?</b></summary>

`dict["key"]` raises a `KeyError` if the key is missing. `get` returns `None`, or a default you pass in.

</details>

<details>
<summary><b>10. How do you merge two dictionaries?</b></summary>

`{**d1, **d2}`, `d1 | d2` (Python 3.9+) or `d1.update(d2)`, which changes `d1` in place. If both have the same key, the value from `d2` wins.

</details>

## 04 · Control Flow

📖 Notes: [04_control_flow/README.md](04_control_flow/README.md)

<details>
<summary><b>1. What is the difference between <code>break</code>, <code>continue</code> and <code>pass</code>?</b></summary>

`break` exits the loop. `continue` skips to the next iteration. `pass` does nothing and only exists as a placeholder for an empty block.

</details>

<details>
<summary><b>2. What does <code>else</code> on a <code>for</code> or <code>while</code> loop do?</b></summary>

It runs when the loop ends normally, meaning **without hitting `break`**. It is useful for searches: "item not found".

</details>

<details>
<summary><b>3. What is a list comprehension? Is it faster than a loop?</b></summary>

It is a short syntax for building a list: `[expr for x in iterable if cond]`. It is usually a little faster than `append` in a loop, because it is optimised internally, and it is more readable for simple cases.

</details>

<details>
<summary><b>4. What is the difference between a list comprehension and a generator expression?</b></summary>

`[x for x in data]` builds the **whole list in memory**. `(x for x in data)` creates a **generator** that produces items one at a time, on demand. That is memory-efficient for large data.

</details>

<details>
<summary><b>5. Does Python have a switch statement?</b></summary>

Since Python 3.10 it has `match`/`case` (structural pattern matching). Before that, people used `if`/`elif` chains or a dict that maps keys to functions.

</details>

<details>
<summary><b>6. What is the difference between <code>for</code> and <code>while</code>?</b></summary>

Use `for` to go over an iterable or a known range. Use `while` to repeat until a condition changes, when you don't know the number of iterations in advance.

</details>

<details>
<summary><b>7. What does <code>range()</code> return?</b></summary>

A `range` object. It is a lazy, memory-efficient sequence, not a list. `range(10**9)` uses almost no memory.

</details>

<details>
<summary><b>8. Print FizzBuzz from 1 to 15.</b></summary>

```python
for i in range(1, 16):
    if i % 15 == 0: print("FizzBuzz")
    elif i % 3 == 0: print("Fizz")
    elif i % 5 == 0: print("Buzz")
    else: print(i)
```

</details>

## 05 · Functions

📖 Notes: [05_functions/README.md](05_functions/README.md)

<details>
<summary><b>1. What are <code>*args</code> and <code>**kwargs</code>?</b></summary>

`*args` collects extra positional arguments into a tuple. `**kwargs` collects extra keyword arguments into a dict. They let a function accept any number of arguments. The names are only a convention; the `*` and `**` are what matter.

</details>

<details>
<summary><b>2. Explain the mutable default argument problem.</b></summary>

Default values are evaluated **once**, when the function is defined. A mutable default like `[]` is shared across all calls, so changes build up between calls. Fix it with `def f(x=None): if x is None: x = []`.

</details>

<details>
<summary><b>3. Does Python pass arguments by value or by reference?</b></summary>

Neither exactly. It is **"pass by object reference"** (also called pass by assignment). The function gets a reference to the same object. If the object is mutable (a list), changing it inside the function affects the caller. Rebinding the name (`x = ...`) inside the function does not.

</details>

<details>
<summary><b>4. What is the LEGB rule?</b></summary>

The order in which Python looks up names: Local, Enclosing, Global, Built-in.

</details>

<details>
<summary><b>5. What is the difference between <code>global</code> and <code>nonlocal</code>?</b></summary>

`global` lets you assign to a module-level variable from inside a function. `nonlocal` lets a nested function assign to a variable in its enclosing function's scope.

</details>

<details>
<summary><b>6. What is a lambda function? What are its limits?</b></summary>

A small anonymous function written in one expression: `lambda args: expr`. It cannot contain statements (no `if` blocks, loops or assignments) and has no name in tracebacks. Use `def` for anything non-trivial.

</details>

<details>
<summary><b>7. What is a closure?</b></summary>

An inner function that captures variables from its enclosing function and keeps them alive after the outer function returns. For example, `make_multiplier(2)` returns a function that remembers `n=2`.

</details>

<details>
<summary><b>8. What does &quot;functions are first-class objects&quot; mean?</b></summary>

Functions can be treated like any other value: stored in variables, passed as arguments, returned from other functions and kept in data structures.

</details>

<details>
<summary><b>9. What is the difference between <code>map</code>/<code>filter</code> and list comprehensions?</b></summary>

They do the same job. `map` and `filter` return lazy iterators. Comprehensions are generally considered more Pythonic and readable, especially when you would otherwise need a lambda.

</details>

<details>
<summary><b>10. What is a docstring?</b></summary>

A string literal on the first line of a function, class or module that documents it. You can read it with `help(func)` or `func.__doc__`.

</details>

## 06 · Object-Oriented Programming (OOP)

📖 Notes: [06_oop/README.md](06_oop/README.md)

<details>
<summary><b>1. What is the difference between a class and an object?</b></summary>

A class is a blueprint or template. An object is a concrete instance created from it, with its own data.

</details>

<details>
<summary><b>2. What is <code>self</code>?</b></summary>

A reference to the current instance. Python passes it automatically as the first argument of instance methods. The name `self` is only a convention.

</details>

<details>
<summary><b>3. Is <code>__init__</code> a constructor?</b></summary>

It is an **initialiser**. `__new__` creates the object, and `__init__` sets up its attributes. In everyday conversation people call `__init__` the constructor.

</details>

<details>
<summary><b>4. Explain the 4 pillars of OOP.</b></summary>

Encapsulation bundles data with methods and hides internal details. Inheritance lets a child class reuse its parent's code. Polymorphism means one interface with many implementations. Abstraction exposes only the essential behaviour (abstract base classes).

</details>

<details>
<summary><b>5. What is the difference between <code>_var</code> and <code>__var</code>?</b></summary>

`_var` is a convention meaning "internal use". `__var` triggers name mangling to `_ClassName__var`, which avoids accidental overrides in subclasses. Neither is truly private.

</details>

<details>
<summary><b>6. What is the difference between <code>@classmethod</code>, <code>@staticmethod</code> and an instance method?</b></summary>

An instance method receives `self` and works on one object. A class method receives `cls` and is used for factory methods and class-level state. A static method receives nothing automatically; it is a plain function grouped inside the class.

</details>

<details>
<summary><b>7. What is the difference between <code>__str__</code> and <code>__repr__</code>?</b></summary>

`__str__` is the readable output for end users (`print`). `__repr__` is the unambiguous output for developers, ideally valid code that could recreate the object. If `__str__` is missing, Python falls back to `__repr__`.

</details>

<details>
<summary><b>8. What is MRO?</b></summary>

The Method Resolution Order: the order in which Python searches classes for a method when there is (multiple) inheritance. It uses the C3 linearisation algorithm. You can see it with `ClassName.__mro__`.

</details>

<details>
<summary><b>9. What is <code>super()</code> used for?</b></summary>

It calls a method of the parent class (following the MRO). It is most often used to run the parent's `__init__` from a child class.

</details>

<details>
<summary><b>10. What is a dataclass and when would you use one?</b></summary>

A decorator that generates `__init__`, `__repr__`, `__eq__` and more for classes that mainly store data. It means less boilerplate and fewer bugs.

</details>

<details>
<summary><b>11. What is duck typing?</b></summary>

Python checks behaviour, not type. If an object has the method you need, you can use it, whatever its class.

</details>

<details>
<summary><b>12. What is the difference between composition and inheritance?</b></summary>

Inheritance is "is-a" (a child extends its parent). Composition is "has-a" (an object contains other objects). Composition is usually more flexible.

</details>

## 07 · Errors & Files

📖 Notes: [07_errors_and_files/README.md](07_errors_and_files/README.md)

<details>
<summary><b>1. What is the difference between an error and an exception?</b></summary>

A syntax error is detected before the code runs and can't be caught. An exception happens at runtime and can be handled with `try`/`except`.

</details>

<details>
<summary><b>2. Explain <code>try</code>, <code>except</code>, <code>else</code> and <code>finally</code>.</b></summary>

`try` holds the risky code. `except` handles specific errors. `else` runs only if no exception happened. `finally` always runs, and is used for cleanup.

</details>

<details>
<summary><b>3. Why is a bare <code>except:</code> bad?</b></summary>

It catches everything, including `KeyboardInterrupt` and `SystemExit`, and it hides real bugs. Catch specific exceptions instead, or `Exception` at most, and log the error.

</details>

<details>
<summary><b>4. How do you create a custom exception?</b></summary>

Subclass `Exception`: `class MyError(Exception): pass`. Add an `__init__` with extra attributes if you need them.

</details>

<details>
<summary><b>5. What is the difference between <code>raise</code> and <code>raise ... from e</code>?</b></summary>

`raise X from e` creates a new exception and links the original as its `__cause__`, so the traceback shows both. A bare `raise` re-raises the current exception unchanged.

</details>

<details>
<summary><b>6. What is a context manager?</b></summary>

An object that implements `__enter__` and `__exit__`, used with `with`. It guarantees setup and cleanup (closing files, releasing locks) even when an error happens. You can also write one with `@contextmanager` and `yield`.

</details>

<details>
<summary><b>7. What is the difference between <code>read()</code>, <code>readline()</code> and <code>readlines()</code>?</b></summary>

`read()` returns the whole file as one string. `readline()` returns one line. `readlines()` returns a list of all lines. For big files, loop over the file object instead.

</details>

<details>
<summary><b>8. What is the difference between <code>json.dump</code> and <code>json.dumps</code>?</b></summary>

`dumps` returns a JSON **string**. `dump` writes JSON to a **file**. The same goes for `loads` and `load`.

</details>

<details>
<summary><b>9. What is EAFP?</b></summary>

"Easier to Ask Forgiveness than Permission". You try the operation and handle the exception, instead of checking first. It is the Pythonic style.

</details>

<details>
<summary><b>10. How would you read a 10 GB file?</b></summary>

Don't call `read()`. Loop over the file line by line (`for line in f`), or read fixed-size chunks with `f.read(chunk_size)`. That way memory use stays small.

</details>

## 08 · Modules, Packages & Virtual Environments

📖 Notes: [08_modules_and_venv/README.md](08_modules_and_venv/README.md)

<details>
<summary><b>1. What is the difference between a module and a package?</b></summary>

A module is a single `.py` file. A package is a directory of modules, usually with an `__init__.py`.

</details>

<details>
<summary><b>2. What does <code>if __name__ == &quot;__main__&quot;:</code> do?</b></summary>

It runs code only when the file is executed directly, not when it's imported. This lets a file be both a reusable module and a script.

</details>

<details>
<summary><b>3. What is <code>__init__.py</code> for?</b></summary>

It marks a directory as a package and runs when the package is imported. It is often used to expose a clean public API or to set up the package.

</details>

<details>
<summary><b>4. What is a virtual environment, and why use one?</b></summary>

An isolated Python environment for each project, with its own installed packages. It prevents version conflicts between projects and makes setups reproducible.

</details>

<details>
<summary><b>5. What is <code>requirements.txt</code>?</b></summary>

A file that lists a project's dependencies, usually with pinned versions. You create it with `pip freeze > requirements.txt` and install from it with `pip install -r requirements.txt`.

</details>

<details>
<summary><b>6. How does Python find a module when you import it?</b></summary>

It checks `sys.modules` (the cache) first. Then it searches `sys.path` in order: the script's folder, `PYTHONPATH`, the standard library, then `site-packages`.

</details>

<details>
<summary><b>7. What is the difference between <code>import module</code> and <code>from module import name</code>?</b></summary>

`import module` binds the module name, and you access things as `module.name`. That is clear about where names come from. `from module import name` binds only that name directly, which is shorter but can cause naming clashes.

</details>

<details>
<summary><b>8. What is the difference between absolute and relative imports?</b></summary>

An absolute import uses the full path from the project root (`from shopkit.pricing import x`). A relative import uses dots for the current package (`from .pricing import x`) and only works inside packages.

</details>

<details>
<summary><b>9. What happens if you import the same module twice?</b></summary>

It runs only once. Later imports use the cached module from `sys.modules`.

</details>

<details>
<summary><b>10. What is the difference between pip and conda?</b></summary>

pip installs Python packages from PyPI. conda is a package **and** environment manager that can also install non-Python dependencies (such as C libraries). It is popular in data science.

</details>

## 09 · Advanced Python

📖 Notes: [09_advanced/README.md](09_advanced/README.md)

<details>
<summary><b>1. What is the difference between an iterable and an iterator?</b></summary>

An iterable can be looped over: it has `__iter__`, which returns an iterator. An iterator produces values with `__next__`, keeps track of its state, and raises `StopIteration` at the end. Every iterator is iterable, but not every iterable is an iterator (a list, for example).

</details>

<details>
<summary><b>2. What is a generator, and why use one?</b></summary>

A function that uses `yield` to produce values lazily, one at a time, pausing between them. It is memory-efficient for large or infinite sequences, and it is a simple way to write an iterator.

</details>

<details>
<summary><b>3. What is the difference between <code>yield</code> and <code>return</code>?</b></summary>

`return` ends the function and sends back one value. `yield` sends back a value and **pauses** the function, keeping its state, so it can resume and produce more values.

</details>

<details>
<summary><b>4. What is the difference between a generator expression and a list comprehension?</b></summary>

`(x for x in data)` is lazy and uses almost no memory, but it can only be used once. `[x for x in data]` builds the whole list in memory, and it can be reused and indexed.

</details>

<details>
<summary><b>5. What is a decorator?</b></summary>

A function that takes a function and returns a new function that adds behaviour around it. `@dec` above `def f` means `f = dec(f)`. Typical uses are logging, timing, caching, authentication checks and retries.

</details>

<details>
<summary><b>6. Why use <code>functools.wraps</code>?</b></summary>

It copies the original function's `__name__`, `__doc__` and other metadata onto the wrapper. Without it, debugging, logging and documentation all show `wrapper` instead of the real function name.

</details>

<details>
<summary><b>7. How do you write a decorator that takes arguments?</b></summary>

Add an extra outer function: `def repeat(n): def decorator(func): def wrapper(...): ...`. `@repeat(3)` first calls `repeat(3)`, which returns the real decorator.

</details>

<details>
<summary><b>8. What does <code>lru_cache</code> do?</b></summary>

It memoises a function: it caches results by their arguments, so repeated calls return instantly. It turns recursive Fibonacci from exponential time into linear time.

</details>

<details>
<summary><b>9. Are type hints enforced in Python?</b></summary>

No. They are ignored at runtime. They help with readability and IDE autocomplete, and static checkers like `mypy` and libraries like Pydantic or FastAPI make use of them.

</details>

<details>
<summary><b>10. What is the GIL?</b></summary>

The Global Interpreter Lock in CPython allows only one thread to execute Python bytecode at a time. Threads still help with I/O-bound tasks. For CPU-bound tasks, use multiprocessing.

</details>

<details>
<summary><b>11. How would you process a 50 GB log file and count the error lines?</b></summary>

Use a generator pipeline that reads one line at a time: `sum(1 for line in open(path) if "ERROR" in line)`. The memory use stays constant whatever the file size.

</details>

## 10 · Mini Project: Expense Tracker

📖 Notes: [10_mini_project/README.md](10_mini_project/README.md)

### Interview practice: talk about this project

**"Walk me through your project."**
> "It's an expense tracker in Python with two interfaces, a terminal app and a Streamlit web app. I split it into modules by responsibility: a dataclass model, a tracker class for the business logic, a reports module that only builds text, and a storage module for JSON and CSV. Only the two UI files do input and output, so adding the web version didn't change any logic, and everything is covered by 41 tests. Expenses validate themselves in `__post_init__`, I used custom exceptions for user errors, and saving goes through a temporary file so a crash can't corrupt the data. The CSV export is the starting point for analysing the data with pandas."

**Likely follow-up questions:**
1. *How would you add a database?* Only `storage.py` would change, because the rest of the app only calls `load()` and `save()`.
2. *How do you test code that uses `input()`?* Keep the logic out of the input code (as here), or replace `input` with `unittest.mock.patch`.
3. *Why is `filter` a generator?* It doesn't build a list it might not need, and the caller decides whether to loop, count or convert it with `list()`.
4. *What happens if the JSON file is corrupted?* `load()` turns any parsing or validation error into a `StorageError`, the app shows a clear message, and it exits without overwriting the file.
5. *What's the time complexity of deleting an expense?* O(n), because it scans the list. A dict keyed by ID would make lookup O(1). That's fine for thousands of expenses and worth changing for millions.

## 11 · NumPy: Fast Numbers in Python

📖 Notes: [11_numpy/README.md](11_numpy/README.md)

<details>
<summary><b>1. Why is NumPy faster than Python lists?</b></summary>

Arrays store items of **one type** in **one contiguous block of memory**, and operations run in compiled C loops. A Python list stores pointers to separate Python objects, each with its own type information, so every operation goes through the slow interpreter.

</details>

<details>
<summary><b>2. What is vectorisation?</b></summary>

Replacing explicit Python loops with operations on whole arrays (`a * 2` instead of looping). It is faster and shorter.

</details>

<details>
<summary><b>3. What is broadcasting?</b></summary>

NumPy's rule for combining arrays of different shapes. Compare shapes from the right; dimensions fit if they are equal or one of them is 1. The smaller array is virtually stretched, without copying.

</details>

<details>
<summary><b>4. What is the difference between a view and a copy?</b></summary>

A view shares memory with the original array (basic slices, `reshape`, `ravel`), so changes affect both. A copy is independent (`.copy()`, `flatten()`, boolean and fancy indexing).

</details>

<details>
<summary><b>5. What does <code>axis=0</code> mean?</b></summary>

Operate down the rows, giving one result per column. `axis=1` operates across the columns, giving one result per row.

</details>

<details>
<summary><b>6. What is the difference between <code>flatten()</code> and <code>ravel()</code>?</b></summary>

Both return a 1-D array. `flatten()` always copies. `ravel()` returns a view when possible, which is faster and uses less memory.

</details>

<details>
<summary><b>7. What does <code>-1</code> mean in <code>reshape</code>?</b></summary>

"Work out this dimension from the others." `arange(12).reshape(3, -1)` gives shape `(3, 4)`.

</details>

<details>
<summary><b>8. Why is <code>np.nan == np.nan</code> False?</b></summary>

By the IEEE floating-point standard, NaN is not equal to anything, including itself. Use `np.isnan()` to find NaNs.

</details>

<details>
<summary><b>9. What is the difference between <code>*</code> and <code>@</code>?</b></summary>

`*` multiplies element by element. `@` is matrix multiplication (the dot product).

</details>

<details>
<summary><b>10. How do you make random results reproducible?</b></summary>

Create a generator with a fixed seed: `rng = np.random.default_rng(42)`, and use `rng` for all random numbers.

</details>

<details>
<summary><b>11. How would you replace all negative values in an array with 0?</b></summary>

`np.where(a < 0, 0, a)` (returns a new array), `a[a < 0] = 0` (in place), or `np.maximum(a, 0)`.

</details>

<details>
<summary><b>12. How do you normalise every column of a 2-D array?</b></summary>

`(X - X.mean(axis=0)) / X.std(axis=0)`. Broadcasting applies each column's mean and standard deviation to that column.

</details>

## 12 · Pandas: Working with Tables of Data

📖 Notes: [12_pandas/README.md](12_pandas/README.md)

<details>
<summary><b>1. What is the difference between a Series and a DataFrame?</b></summary>

A Series is a single labelled 1-D column. A DataFrame is a 2-D table made of several Series that share an index.

</details>

<details>
<summary><b>2. What is the difference between <code>loc</code> and <code>iloc</code>?</b></summary>

`loc` selects by **labels** (index labels and column names), and slices include the end. `iloc` selects by integer **positions**, and slices exclude the end.

</details>

<details>
<summary><b>3. How do you handle missing values?</b></summary>

First measure them (`isna().sum()`), then decide based on the amount and the meaning: drop rows (`dropna`), fill with a statistic (mean, median or mode), fill with a label like "Unknown", or interpolate time series. Always document the choice, because it affects the results.

</details>

<details>
<summary><b>4. What is the difference between <code>merge</code>, <code>join</code> and <code>concat</code>?</b></summary>

`merge` combines tables on key columns, like SQL joins. `join` is a shortcut that merges on the index. `concat` stacks tables vertically (more rows) or horizontally (more columns) without matching keys.

</details>

<details>
<summary><b>5. Explain inner, left and outer joins.</b></summary>

Inner keeps only matching keys. Left keeps all rows of the left table and fills NaN where the right has no match. Outer keeps all keys from both tables.

</details>

<details>
<summary><b>6. How does <code>groupby</code> work?</b></summary>

Split–apply–combine: split the rows into groups by a key, apply an aggregation (sum, mean, count...) to each group, and combine the results into a new table.

</details>

<details>
<summary><b>7. What is the difference between <code>apply</code>, <code>map</code> and vectorised operations?</b></summary>

Vectorised operations work on whole columns in compiled code, so they're the fastest. `map` replaces each value in a Series using a dict or function. `apply` calls a Python function per row or column; it's flexible but slow, so use it only when needed.

</details>

<details>
<summary><b>8. What is the difference between <code>pivot_table</code> and <code>groupby</code>?</b></summary>

Both aggregate. `pivot_table` also reshapes the result into a 2-D grid (one key as rows, another as columns), like an Excel pivot table. `groupby` gives a long format.

</details>

<details>
<summary><b>9. How do you find and remove duplicates?</b></summary>

`df.duplicated()` marks duplicates and `df.drop_duplicates()` removes them. Use `subset=[...]` to compare only some columns and `keep="first"`/`"last"` to choose which one stays.

</details>

<details>
<summary><b>10. Why did my integer column become float after a merge?</b></summary>

A left or outer join inserted `NaN` for unmatched rows, and NaN is a float, so pandas upcast the column. Convert it back with `astype(int)` after handling the NaNs, or use the nullable `"Int64"` dtype.

</details>

<details>
<summary><b>11. What is Copy-on-Write in pandas 3?</b></summary>

Any DataFrame or Series derived from another behaves as a copy, so changing it never changes the original. Chained assignment (`df["a"][mask] = x`) no longer works; use `df.loc[mask, "a"] = x`.

</details>

<details>
<summary><b>12. How would you find the top 3 products by revenue in each category?</b></summary>

```python
(df.groupby(["category", "product"])["revenue"].sum()
   .groupby(level="category", group_keys=False).nlargest(3))
```

</details>

## 13 · Visualisation: Matplotlib & Seaborn

📖 Notes: [13_visualisation/README.md](13_visualisation/README.md)

<details>
<summary><b>1. What is the difference between Matplotlib and Seaborn?</b></summary>

Matplotlib is the low-level plotting library that controls every element. Seaborn is a high-level library built on it that works directly with DataFrames, handles grouping (`hue`) and statistics, and has good defaults. In practice you use Seaborn for the chart and Matplotlib to customise it.

</details>

<details>
<summary><b>2. What is the difference between a Figure and an Axes?</b></summary>

The Figure is the whole canvas. An Axes is one plot inside it, with its own axes, title and data. One Figure can hold many Axes (`plt.subplots(2, 2)`).

</details>

<details>
<summary><b>3. When would you use a histogram vs a bar chart?</b></summary>

A histogram shows the **distribution of one numeric variable** by grouping values into bins, so the bars touch. A bar chart compares a value across **categories**, and the order of the bars can be changed.

</details>

<details>
<summary><b>4. How do you read a box plot?</b></summary>

The box covers the middle 50% of the data (from Q1 to Q3, the IQR), and the line inside is the median. The whiskers extend to the furthest points within 1.5 × IQR, and the points beyond them are drawn as outliers.

</details>

<details>
<summary><b>5. Why might a pie chart be a bad choice?</b></summary>

People compare angles and areas poorly, so similar slices look the same. A pie also can't show more than a handful of categories. A sorted bar chart makes comparisons easy.

</details>

<details>
<summary><b>6. Why should bar charts start at zero?</b></summary>

The length of the bar encodes the value. Starting at, say, 90 makes 95 look twice as big as 92.5. (Line charts can sometimes zoom in, because they show change, not size.)

</details>

<details>
<summary><b>7. What&#x27;s wrong with dual-axis charts?</b></summary>

The two scales can be stretched independently, so the lines can be made to cross, diverge or overlap at will. The apparent relationship is a choice by the chart's author, not a fact in the data. Use two charts, or index both series to a common starting point.

</details>

<details>
<summary><b>8. How would you visualise the relationship between two numeric variables?</b></summary>

A scatter plot, with a trend line (`sns.regplot`) and the correlation coefficient. For many points, use transparency or a hexbin/density plot.

</details>

<details>
<summary><b>9. How do you make charts accessible to colour-blind readers?</b></summary>

Use a validated colour-blind-safe palette, don't rely on colour alone (add labels, patterns or markers), keep good contrast, and offer the data as a table as well.

</details>

<details>
<summary><b>10. What chart would you use to show sales by region over 12 months?</b></summary>

A line chart with one line per region (up to about 5 lines, labelled directly), or small multiples (one small chart per region on a shared axis) if there are more regions.

</details>

## 14 · Statistics for Data Science

📖 Notes: [14_statistics/README.md](14_statistics/README.md)

<details>
<summary><b>1. Mean or median: which would you report for salaries, and why?</b></summary>

The median. Salaries are right-skewed, and a few very high earners pull the mean up, so the median better describes a typical employee.

</details>

<details>
<summary><b>2. What is a p-value?</b></summary>

The probability of seeing data at least as extreme as yours **if the null hypothesis were true**. It is *not* the probability that the null hypothesis is true.

</details>

<details>
<summary><b>3. What are Type I and Type II errors?</b></summary>

A Type I error is a false positive: rejecting a true null hypothesis (its probability is α). A Type II error is a false negative: missing a real effect (probability β). Lowering α reduces Type I errors but increases Type II errors, unless you collect more data.

</details>

<details>
<summary><b>4. Explain the Central Limit Theorem and why it matters.</b></summary>

The distribution of sample means approaches a normal distribution as the sample size grows, whatever the shape of the original data. It's why we can build confidence intervals and run t-tests on non-normal data with large enough samples.

</details>

<details>
<summary><b>5. What is a confidence interval?</b></summary>

A range built by a method that captures the true parameter in a stated percentage (e.g. 95%) of repeated samples. Wider intervals mean more uncertainty; larger samples give narrower intervals.

</details>

<details>
<summary><b>6. When would you use Mann-Whitney U instead of a t-test?</b></summary>

When the data is skewed, has outliers, or is ordinal (like ratings), especially with small samples. Mann-Whitney compares ranks instead of means.

</details>

<details>
<summary><b>7. What is the difference between standard deviation and standard error?</b></summary>

Standard deviation measures the spread of the **data**. Standard error measures the uncertainty of an **estimate** (like the mean): `SE = SD / √n`, so it shrinks as the sample grows.

</details>

<details>
<summary><b>8. How would you design an A/B test?</b></summary>

Define one primary metric and the minimum effect worth detecting. Calculate the sample size for the power you want (often 80%) at α = 0.05. Randomly split users, run until the planned size is reached without peeking, then test (two-proportion test or chi-square) and report both the p-value and the effect size with a confidence interval.

</details>

<details>
<summary><b>9. What is the difference between statistical and practical significance?</b></summary>

Statistical significance says an effect is unlikely to be chance. Practical significance asks whether it's big enough to matter. With huge samples, tiny useless effects become statistically significant.

</details>

<details>
<summary><b>10. What is p-hacking, and how do you avoid it?</b></summary>

Trying many analyses until something is significant, then reporting only that one. Avoid it by planning your hypotheses in advance, correcting for multiple comparisons, and reporting every test you ran.

</details>

<details>
<summary><b>11. Pearson vs Spearman correlation?</b></summary>

Pearson measures **linear** relationships and is sensitive to outliers. Spearman uses ranks, so it measures any **monotonic** (consistently rising or falling) relationship and is robust to outliers.

</details>

<details>
<summary><b>12. What does a chi-square test of independence tell you?</b></summary>

Whether two categorical variables are associated. It compares the observed counts in a contingency table with the counts expected if the variables were independent.

</details>

## 16 · Machine Learning: Predicting Bike Demand

📖 Notes: [16_machine_learning/README.md](16_machine_learning/README.md)

<details>
<summary><b>1. What&#x27;s the difference between supervised and unsupervised learning?</b></summary>

Supervised learning trains on examples with known answers (labels) to predict those answers for new data, as in regression and classification. Unsupervised learning finds structure in data without labels, as in clustering and dimensionality reduction.

</details>

<details>
<summary><b>2. What&#x27;s the difference between regression and classification?</b></summary>

Regression predicts a continuous number (rides per hour). Classification predicts a category (spam or not spam).

</details>

<details>
<summary><b>3. Why do we split data into training and test sets?</b></summary>

To measure how the model performs on data it has never seen, which is what matters in real use. Evaluating on the training data rewards memorisation.

</details>

<details>
<summary><b>4. Why not split time-series data randomly?</b></summary>

Neighbouring time points are very similar, so a random split lets the model "peek" at the hours around each test hour. Train on the past and test on the future, and use `TimeSeriesSplit` for cross-validation.

</details>

<details>
<summary><b>5. What is data leakage? Give an example.</b></summary>

When the training features contain information that wouldn't be available at prediction time, or information derived from the target. Example: using `registered` riders to predict total rides, or scaling the data using statistics from the test set.

</details>

<details>
<summary><b>6. What is overfitting, and how do you detect and prevent it?</b></summary>

The model learns noise in the training data and does poorly on new data. You detect it by a large gap between training and validation scores. Prevent it with more data, simpler models, regularisation, early stopping, or limiting tree depth and leaf size.

</details>

<details>
<summary><b>7. What is cross-validation?</b></summary>

Training and validating several times on different splits of the training data, then averaging the scores. It gives a more reliable estimate than a single split and is used to choose hyperparameters.

</details>

<details>
<summary><b>8. MAE vs RMSE: which would you use?</b></summary>

MAE when every error counts equally and you want an easy-to-explain number. RMSE when large errors are disproportionately costly, because it squares the errors before averaging.

</details>

<details>
<summary><b>9. Why use a Pipeline in scikit-learn?</b></summary>

It ensures preprocessing is fitted only on the training data (no leakage), keeps training and prediction identical, works with cross-validation and grid search, and can be saved as one object.

</details>

<details>
<summary><b>10. How does a random forest differ from gradient boosting?</b></summary>

A random forest trains many trees **independently** on random samples and averages them, which reduces variance. Gradient boosting trains trees **one after another**, each correcting the errors of the ones before, which reduces bias. Boosting often scores higher but needs more careful tuning.

</details>

<details>
<summary><b>11. What is feature importance, and what are its pitfalls?</b></summary>

A measure of how much a model relies on each feature. Permutation importance shuffles a feature and measures how much the error increases. Pitfalls: correlated features share importance, it only reflects features that vary in the evaluation data, and importance is not causation.

</details>

<details>
<summary><b>12. Your model scores R² = 0.99. What do you do?</b></summary>

Be suspicious. Check for leakage (features derived from the target or from the future), check the split (random splits on time data), and check whether the test set accidentally overlaps with training.

</details>
